Agent Hub MCP 安装指南

把 Claude Code / Cursor 连到 hub.stifer.xyz（JWT 登录优先，无需 API Key）

给 AI / Agent 读的完整教程： https://hub.stifer.xyz/mcp.md · 发现页 /llms.txt
把该 URL 丢给 AI 即可按步骤自配 MCP，无需本页交互。

1 配置 MCP（推荐：远程 HTTP）

官方主路径推荐：直接连接远程 Streamable HTTP 入口 https://hub.stifer.xyz/mcp，无需克隆代码或安装本地 Node 依赖。

方式 A：命令行一键添加（Claude Code）

claude mcp add --transport http hub https://hub.stifer.xyz/mcp

方式 B：写入项目 .mcp.json 或用户配置

{
  "mcpServers": {
    "hub": {
      "type": "http",
      "url": "https://hub.stifer.xyz/mcp"
    }
  }
}
人侧不需要 API Key。 不要在配置里塞 HUB_API_KEY，除非你要跑无人值守 heartbeat/锁。

2 备用方案：本地 Node stdio（可选）

仅供本地二次开发调试或离线备用方案使用：

git clone https://github.com/toustifer/agent-hub.git
cd agent-hub/mcp-server
npm install

写入配置（把 ABS_PATH 换成你机器上的绝对路径，Windows 用双反斜杠）：

{
  "mcpServers": {
    "hub": {
      "command": "node",
      "args": ["ABS_PATH/mcp-server/index.js"],
      "env": {
        "HUB_API_URL": "https://hub.stifer.xyz"
      }
    }
  }
}

3 登录（MCP hub_login）

  1. 重启 Claude Code，/mcp 看到 hub connected
  2. 调用 hub_login() → 打开返回的浏览器 URL
  3. 在 hub.stifer.xyz 登录（需邮箱验证）→ Approve
  4. 再调用 hub_login({ code }) → JWT 写入 ~/.agent-hub/config.json
  5. hub_list_my_businesses 确认团队

4 团队 code

Dashboard 创建团队后复制标识码，或从 hub_list_my_businesses 读取。可写入：

{
  "business_code": "your-team-code"
}

位置：~/.agent-hub/config.json 或项目 .mycompany/hub-client.json（建议 gitignore）。

5 工具鉴权一览

类型工具鉴权
登录hub_login无
人侧invite / branches / dag / list_*JWT（hub_login）
机器heartbeat / locks / events / create_playbook可选 API Key
